# MP3 Tags Encoding Fix

![Tests](https://github.com/GenkaOk/mp3-tags-encoding-fix/actions/workflows/python-tests.yml/badge.svg)

Другие языки: [English](https://github.com/GenkaOk/mp3-tags-encoding-fix/blob/master/README.md)


Небольшая утилита на Python для чтения ID3-тегов в MP3-файлах, исправления распространённых проблем с кириллицей/кодировками и сохранения исправленных тегов (с возможностью создания резервных копий). Включён набор тестов с мок‑объектами ID3 для покрытия логики обработки.

## Возможности
- Декодирование/исправление строк тегов, закодированных с типичными несовпадениями кодировок (Latin-1 → CP1251 → UTF-8).
- Обработка одной папки или рекурсивный обход директорий.
- Опция создания резервных копий файлов (`-fix.mp3`) или перезаписи оригиналов.
- Режим "пробного запуска" (dry-run) для предварительного просмотра изменений без записи файлов.

## Требования
- Python 3.8+
- mutagen

Установка зависимостей:

```bash
python -m pip install mutagen
```

ИЛИ

```bash
python -m pip install -r requirements.txt
```

## Структура проекта
- mp3_processor.py — основной скрипт и библиотечные функции (включая parse_and_fix_tags и decode_).
- tests/test_mp3_processor.py — набор unit-тестов (использует unittest.mock для подмены EasyID3 и операций с файлами).

## Использование

Запуск скрипта из командной строки:

```bash
python mp3_processor.py ПУТЬ_К_ПАПКЕ [--recursive] [--backup yes|no] [--dry-run]
```

Параметры:
- ПУТЬ_К_ПАПКЕ — папка с MP3‑файлами для обработки.
- --recursive — рекурсивно обойти поддиректории.
- --backup yes|no — создавать резервные копии файлов по умолчанию (`yes`). Если `no`, теги сохраняются в тех же файлах.
- --dry-run — не записывать файлы; только показать, какие изменения были бы внесены.

Примеры:
- Обработать одну директорию и создать резервные копии:
  `python mp3_processor.py ./music --backup yes`
- Обработать рекурсивно и перезаписать оригиналы:
  `python mp3_processor.py ./music --recursive --backup no`
- Предпросмотр изменений без записи:
  `python mp3_processor.py ./music --dry-run`
